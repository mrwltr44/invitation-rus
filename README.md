Веб-приглашение на юбилей в русском стиле. Одна страница, вертикальная прокрутка, мобильный формат.

## Что внутри

```

assets/css/style.css   вёрстка по координатам макета
assets/js/main.js      появление блоков при прокрутке, окно выбора связи
```

## Как устроена вёрстка

Макет мобильный, 402×4411. Все размеры в CSS заданы **в единицах макета** и пересчитываются одной переменной:

```css
--w: min(100vw, 430px);   /* ширина сцены */
--u: calc(var(--w) / 402); /* цена одной единицы макета */
```

Дальше любой размер пишется как `calc(31 * var(--u))` — это ровно 31 пиксель исходного макета. Страница масштабируется целиком, пропорции не плывут ни на узком экране, ни на широком.

Блоки позиционированы абсолютно, координаты взяты из Figma один в один. У каждого элемента в разметке есть `data-node` с идентификатором узла — по нему всегда можно вернуться к исходнику.

## Шрифты

В макете использованы **Yauza TYGRA** (заголовки, дата, время) и **Radiant** (основной текст, плашка адреса). Оба шрифта пришли от дизайнера, лежат в `assets/fonts/` и подключены через `@font-face` в начале `style.css`. Внешних загрузок нет — Google Fonts убран.

```css
--font-display: "Yauza TYGRA", ...;  /* .t--display */
--font-body: "Radiant", ...;         /* .t--body, .pill */
```

Оба начертания единственные, Regular. Поэтому `.t--display` стоит на `font-weight: 400` — иначе браузер сам нарисует фальшивый жир, которого в макете нет. Дальше по стеку идут запасные семейства на случай, если файл шрифта не загрузится.

## Изображения

Все иллюстрации выгружены из Figma и **лежат в репозитории**, а не подтягиваются по ссылке: ссылки на ассеты Figma живут около семи дней.

Исходники весили 26 МБ. После пересчёта под реальные размеры отображения (с двойным запасом под retina) и перевода в WebP осталось 1.81 МБ.

Съедобные значки в блоке про забавы в макете обрезаны скруглённой плашкой (Mask group). Обрезка сделана рамкой `.treat` с `overflow: hidden` и `border-radius`, картинка внутри — `.treat__art`. Тем же приёмом обрезан снимок гостей в блоке про образ (`.dress-photo`). Отдельные файлы масок не нужны.

Выгрузку из Figma стоит проверять по первым байтам файла, а не по расширению: экспорт умеет отдать SVG под именем `.png`, и такая «картинка» молча не отрисуется.

## Анимации

Появление блоков по мере прокрутки: `IntersectionObserver` вешает класс `.is-in`, дальше работает CSS-переход. Порядок внутри группы задаётся атрибутом `data-delay` в миллисекундах.

Связка баранок покачивается на верёвке после появления.

Кнопка внизу открывает окно выбора мессенджера — MAX или Telegram. Окно закрывается крестиком, щелчком по завесе и клавишей Esc; пока оно открыто, фокус ходит по кругу внутри него и не уходит на страницу под ним.

Всё это выключается при `prefers-reduced-motion: reduce` — у кого в системе стоит запрет на анимацию, увидит статичную страницу без рывков.

## Разработка

Отдельной сборки нет, это статические файлы. Достаточно поднять любой локальный сервер:

```powershell
python -m http.server 8000
```

и открыть `http://localhost:8000`. Двойным щелчком тоже откроется, но по `file://` Chrome не грузит шрифты из `assets/fonts/` — заголовки покажутся запасным начертанием.
