# Приглашение «Гости званные, да желанные!»

Веб-приглашение на юбилей, 22 августа 2026. Одностраничник, статика, GitHub Pages.

## Суть проекта

Дизайнер отдал макет в Figma — мобильный, 402×3134, русский стиль: орнаменты-вышивка, самовар, берёза, резной наличник, баранки. Задача была развернуть его в живую страницу с анимациями появления и выложить по ссылке, которую можно разослать гостям.

## Границы

- Это **разовый артефакт под конкретное событие**, а не продукт. Не наращивать: без сборщиков, без фреймворков, без CMS.
- Правки визуала — только по макету. Если чего-то нет в Figma, сначала спросить Walter, а не придумывать.
- Тексты приглашения стилизованы под старину («пир честной», «палаты купеческие»). Любые новые строки писать в том же ладу, современную канцелярщину не мешать.

## Что важно помнить

- Работа идёт **с копией** файла Figma в drafts Walter'а. Оригинал у дизайнера открыт только на просмотр, а Figma MCP требует «Can edit» даже для чтения. Правки дизайнера в копию не прилетают — при обновлении макета копию снимать заново.
- Ассеты **лежат в репозитории**. Ссылки на выгрузки Figma живут около семи дней, подтягивать по ним нельзя.
- Шрифты макета (`Yauza TYGRA`, `Radiant`) лицензионные и не подключены. Стоят открытые аналоги, стек в CSS готов принять оригиналы без переписывания вёрстки.
- Все размеры в CSS — в единицах макета через `var(--u)`. Не подставлять сырые пиксели: сломается масштабирование.
- `z-index` расставлен сквозным списком 1..17 по порядку узлов в Figma. Добавляешь слой — вставляй в этот порядок, а не поверх всего.

## Проверка

Открывать через локальный сервер (`python -m http.server 8000`), не двойным щелчком: по `file://` не работают CSS-маски у съедобных значков.

Перед выкладкой смотреть на настоящем телефоне — макет мобильный, десктопного варианта дизайнер не давал.
