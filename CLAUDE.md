# Приглашение «Гости званные, да желанные!»

Веб-приглашение на юбилей, 22 августа 2026. Одностраничник, статика, GitHub Pages.

## Суть проекта

Дизайнер отдал макет в Figma — мобильный, 402×4411, русский стиль: орнаменты-вышивка, самовар, берёза, резной наличник, баранки. Задача была развернуть его в живую страницу с анимациями появления и выложить по ссылке, которую можно разослать гостям.

Редакция макета от 2026-07-29 (дизайнер Виктория) добавила табличку «Евгению 35 лет» на первом экране, блок про подобающий образ гостей и кнопку отклика внизу. Высота выросла с 3134 до 4411.

## Границы

- Это **разовый артефакт под конкретное событие**, а не продукт. Не наращивать: без сборщиков, без фреймворков, без CMS.
- Правки визуала — только по макету. Если чего-то нет в Figma, сначала спросить Walter, а не придумывать.
- Тексты приглашения стилизованы под старину («пир честной», «палаты купеческие»). Любые новые строки писать в том же ладу, современную канцелярщину не мешать.

## Что важно помнить

- Работа идёт **с копией** файла Figma в drafts Walter'а. Оригинал у дизайнера открыт только на просмотр, а Figma MCP требует «Can edit» даже для чтения. Правки дизайнера в копию не прилетают — при обновлении макета копию снимать заново, и ключ файла при этом меняется (актуальный записан в шапке design-map).
- Выгруженные из Figma картинки проверять по первым байтам, а не по расширению: экспорт умеет отдать SVG под именем `.png`, и такой файл молча не отрисуется.
- Ассеты **лежат в репозитории**. Ссылки на выгрузки Figma живут около семи дней, подтягивать по ним нельзя.
- Шрифты макета (`Yauza TYGRA`, `Radiant`) пришли от дизайнера 2026-07-28, лежат в `assets/fonts/` и подключены через `@font-face`. Оба в единственном начертании Regular — не ставить им `font-weight` больше 400, браузер нарисует фальшивый жир.
- Все размеры в CSS — в единицах макета через `var(--u)`. Не подставлять сырые пиксели: сломается масштабирование.
- `z-index` расставлен сквозным списком 1..31 по порядку узлов в Figma. Добавляешь слой — вставляй в этот порядок, а не поверх всего: новые узлы дизайнера ложатся в середину стопки, и список приходится перенумеровывать целиком.
- Кнопка «сообщить о своём почтении» открывает окно выбора мессенджера (MAX и Telegram). Макета у окна нет — собрано в ладу страницы; лежит **вне** `.stage`, иначе обрежется его `overflow: hidden`.
- В шрифте `Yauza TYGRA` нет латиницы: браузер подставляет чужие глифы, «MAX» читается как «МАЛ». Любые названия для этого шрифта писать кириллицей.

## Проверка

Открывать через локальный сервер (`python -m http.server 8000`), не двойным щелчком: по `file://` Chrome не грузит шрифты из `assets/fonts/`.

Перед выкладкой смотреть на настоящем телефоне — макет мобильный, десктопного варианта дизайнер не давал.
